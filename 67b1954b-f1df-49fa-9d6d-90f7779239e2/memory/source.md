# 来源范围与重建限制

历史主题: Pi package 包装、启动依赖与共享 Git skill.

本来源以已经形成的历史 memory 归纳为主要材料, 经选择、审阅和纠错重新表达. 原始对话、完整工具日志和此前归档不作为本历史的一部分长期保存; 此处不是逐字节原始证据, 也不依赖旧存储路径或旧 Git 对象才能理解.

只保留有独立恢复价值的知识状态及得到支持的相对顺序. 本文件说明整个来源范围, 不表示较早状态已经知道后续结论. 提交时间是清洁重建时间, 不回填原事件时间. 历史运行报告、本次静态核对和仍未验证的判断分别说明; 本次重建没有运行 Nix、构建或系统操作.

新历史是独立 root, 不关联先前辅助历史或未经审阅的项目 ancestry. 因不保留原始材料, 原始命令输出和精确工作区的复核能力受到限制; 不以归纳摘要替代原始验证证明.

## 选定的历史恢复阶段

1. 以 overrideAttrs 保留 Pi 包语义.
2. 用 extraPackages 管工具并纠正 wrapper 命令.
3. 区分通用 skill 与 Pi extension 能力裁剪.

此前归纳包含 4 个状态, 本次保留 3 个恢复边界; 其余增量在对应完整状态中合并, 不重放逐条修改.

## 后续使用

正式整合前按当前实现核对仍有效的结论. 未解决事项不自动代表当前可复现故障; 历史成功检查不扩展到之后的变更.
