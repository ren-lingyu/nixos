The plan places constraints by actual data dependency and ownership, not their current file or use of moduleInternals. Add seven local validator files: Hosts (metadata and configuration), Users, Features, Niri, Greeter, Proxy and ThinkBook (configuration only). Do not centralize business predicates in generic libraries, flake.nix or a root catch-all validator. Both branches must still return a boolean conjunction rather than old NixOS assertion records. Do not duplicate constraints already enforced by types. Join Host enablement from configuration with UID registrations from Registry metadata, not the adapter-only merged OS view. Keep subset membership rather than equality, allow spare Host registrations and avoid incidental lookup errors when Host selection is invalid. Preserve account/HM projections and all option defaults.

Keep Greeter package mainProgram and nonempty provider checks, Niri monitor/session package production, Greeter monitor/session logic and WireGuard configuration generation.
