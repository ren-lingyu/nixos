## 命令环境

本文中的命令名是逻辑名称. agent 实际执行下列命令时, 必须使用表中对应的绝对路径, 不依赖 PATH 查找. 表中多个逻辑名称对应同一可执行文件时, 均使用该可执行文件并原样传递其后的参数. 后续规则和示例仍使用逻辑名称书写命令.

| 命令名               | 实际可执行文件         |
|----------------------|------------------------|
| `git`                | `@git@`                |
| `git-gaw`, `git gaw` | `@git-agent-workflow@` |
| `realpath`           | `@realpath@`           |

该映射只约束 agent 自身执行的命令. 向用户展示需要其手动执行的命令时, 除非绝对路径本身与问题有关, 仍使用通常的命令名.
